# crowdsense-backtest (보관)

> **이 저장소는 더 이상 수집하지 않습니다.** 2026-09-10에 역할을 마쳤습니다.

CrowdSense 예측 정확도 검증용 관측 데이터를 모으던 곳입니다
([데모](https://crowdsense-jvv1.vercel.app) · 제4회 재난안전데이터 활용 창업경진대회 최우수상).

## 왜 멈췄나

두 가지 이유입니다.

**① 수집 주기를 낼 수 없었습니다.** GitHub Actions 예약 실행은 문서상 "최선 노력"이고,
10분 간격으로 설정해도 실측 **2시간 간격**으로 밀렸습니다. 이 프로젝트에서 재려는 것이
"혼잡 등급이 오르기 몇 분 전에 신호가 떴는가"인데, 2시간 해상도로는 측정 자체가 성립하지
않습니다.

**② 공개 저장소에 예측을 계속 쌓는 것이 API 접근 제어와 모순됐습니다.** 같은 시기에
서비스 API에 인증을 붙였는데, 그 데이터를 공개 저장소에 그대로 올리면 앞뒤가 맞지 않습니다.

## 지금은 어디로

수집·저장 모두 서비스 쪽으로 옮겼습니다.

```
외부 크론 ──► /api/collect (운영 키) ──► Vercel Blob (private)
                                            │
로컬 백테스트 ◄──────────── /api/export (운영 키)
```

수집 로직이 서버에 있어 스키마가 한 곳에만 존재하고, 트리거가 여럿이어도 같은 결과가 나옵니다.
